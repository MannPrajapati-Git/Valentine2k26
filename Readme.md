# ❤️ 3D Valentine Heart Animation

A beautiful **3D Valentine Heart Animation** built using **HTML, CSS, and JavaScript**, featuring a procedural heart build effect, glowing gradient wireframe, smooth camera movement, and falling heart rain.

This project creates a romantic visual scene where a heart forms step-by-step and then fills the screen with raining mini hearts.

## ✨ Features

- 💖 Procedural 3D Heart Generation  
- 🌈 Gradient Wireframe Coloring  
- 🧩 Dynamic Geometry Construction  
- 🌧️ Falling Heart Rain Effect  
- 🎥 Smooth Camera Interaction  
- 🌫️ Depth Fog Environment  
- 💌 Valentine Message Fade-In  
- 📱 Fully Responsive Canvas
